# IT Home Lab

Hands-on Windows, networking, troubleshooting, and IT support labs documented for practical experience.

## Environment

- Windows 11 Pro ARM
- UTM virtual machine
- Standard and administrator user accounts
- PowerShell
- Windows built-in administrative tools

## Purpose

This repository documents hands-on IT support practice performed in a Windows home-lab environment.

The labs focus on troubleshooting methodology, identifying root causes, applying appropriate fixes, and verifying results.
